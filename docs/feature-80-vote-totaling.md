# feature/80: フェーズ4の投票結果表示

## 目的

ドット投票が完了したあと、参加者が投票結果と取り組む課題を確認できるようにする。

## 実装内容

- ルームのフェーズに `phase4` を追加した。
- ホストのフェーズ遷移を `phase1 → phase2 → phase3 → phase4` に拡張した。
- `phase4` では付箋ボードの代わりに投票結果パネルを中央表示するようにした。
- 付箋の追加は `phase4` では表示しない。ホストの「次のフェーズへ」も `phase4` で無効化する。
- 主観票を5点、客観票を1点として集計し、上位3件を表示する。
- 全参加者が主観票・客観票を使い切るまで、投票完了待ちの状態を表示する。
- 首位が同点の場合は、同率の課題をすべて「取り組む課題」として表示する。同率順位は同じ順位として表示する。
- 集計用の atom / molecule / organism を追加し、それぞれに Storybook ストーリーを用意した。

## 既存機能との統合

develop への rebase 時に、グループ化機能と投票結果表示が同じボード表示および WebSocket プロトコルを変更していたため競合した。解消後は次の両方を保持している。

- `phase1`〜`phase3` では既存のグループ表示・グループ名更新を継続する。
- プロトコルの `GroupSchema`、グループ関連メッセージ、および `phase4` を共存させる。
- `phase4` のみ投票結果パネルへ切り替える。
